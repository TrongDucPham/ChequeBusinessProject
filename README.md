Cheque Business Project

A full‑stack web application for managing cheque records, customers, and business operations. This project was developed as part of the coursework for CS 340 – Introduction to Databases at Oregon State University, applying database concepts, CRUD operations, and web application design patterns learned throughout the term.

1/ Overview
This application provides:
    .Create, Update, Delete (CUD) operations for cheque records
    .A responsive, modern UI
    .Form validation and error handling
    .Database‑backed data management
    .Clean routing and modular server structure
The goal of the project is to demonstrate practical database integration and full‑stack development skills.

2/ Academic Acknowledgments
This project incorporates concepts and patterns learned from OSU course modules, including:
Module: Exploration – Implementing CUD Operations in Your App
This module provided foundational guidance for:
    .Designing Create, Update, and Delete routes
    .Handling form submissions and server‑side validation
    .Structuring SQL queries for modifying data
    .Connecting UI elements to backend logic
    .Building maintainable CRUD workflows

These ideas directly shaped the project’s route structure and form‑handling logic.
